= Runbook & Doctor — Layer 3 Plan (write side: serialize the diagnostic layer)
:toc: left

> *For agentic workers:* implement task-by-task; steps use `- [ ]` for tracking. Builds/tests are
> runnable by Claude (compile/test/`pulumi preview` are dry-runs — CLAUDE.md). Single-dev,
> sequential, NO compat shims: when a path is superseded, delete it and update all call sites in the
> same change.

*Goal:* make the stack state self-describing — each checkpoint `ComponentResource` carries its own
serialized consultation report (diagnostic layer only), and the cluster→systemd edge becomes a real
persisted `dependsOn`, behind a single-source `Checkpoint` enum join key.

*Architecture:* per the design (link:layer3-medical-record-design.adoc[layer3-medical-record-design.adoc]):
Pulumi state holds the graph, update history holds the time; we serialize ONLY the diagnostic layer
(`Symptom`/`Dossier`/`RemediationPlan`), per node, additively. The stack's top-level outputs
(`OutputBuilder`) are *untouched* — the Stage-B contract stays byte-identical.

*Tech stack:* Java 25 (flox toolchain), Pulumi-java `ComponentResource`, JGiven (render), JUnit5 +
Mockito (test). Build: `flox activate -- ./mvnw … -pl :seed-master -am`.

*Scope — this plan is the WRITE side only.* The post-hoc reconstruction tool (parse `pulumi stack
export` → rebuild DAG → graft → render) and the "our model = source" renderer flip
(`RunbookRenderingTest` assertion) are a SEPARATE follow-up plan. Reason: you cannot reconstruct what
is not yet written; the write side is independently valuable (state becomes queryable via `pulumi
stack output`) and the runtime runbook already renders from the in-memory model, unchanged.

== Hard guard (do not break)

Top-level stack outputs (everything `OutputBuilder.buildOutputs(...)` emits) stay *byte-identical*:
`handoffReady`→`nextStep`, `bootstrapStatus`, the 7 `cluster*` keys, the systemd-adapter flat keys.
The new diagnostic data lives ONLY *under* each checkpoint `ComponentResource` (via
`registerOutputs`), never at top level. `ClusterReadinessProjectionTest` is the pin and must stay
green unchanged.

package io.nxmatic.rke2lab.controlplane.bdd;

/**
 * The closed set of readiness checkpoints — the single source of truth for a checkpoint's identity,
 * consumed by BOTH the BDD layer (the scenario id / {@code ConsultationReport.checkpointId}) and the
 * Pulumi resources (the resource {@code name} → URN). The resource name is DERIVED from the slug, so
 * the {@code "cluster-readiness"} ↔ {@code "seed-cluster-readiness"} correspondence is structural,
 * not hand-maintained (the clusterApi/cluster-api silent-failure pattern the project guards against).
 *
 * <p>Identity ONLY — never topology. The cluster→systemd-adapter dependency edge lives in the
 * resource's {@code dependsOn} (read back from the persisted state), NOT here; encoding it here would
 * recreate the duplication the medical-record design removes.
 */
public enum Checkpoint {
  SYSTEMD_ADAPTER("systemd-adapter"),
  CLUSTER_READINESS("cluster-readiness");

  private final String slug;

  Checkpoint(String slug) {
    this.slug = slug;
  }

  /** The BDD identity: the scenario id and {@code ConsultationReport.checkpointId}. */
  public String slug() {
    return slug;
  }

  /** The Pulumi resource name (→ URN), derived from the slug. */
  public String resourceName() {
    return "seed-" + slug;
  }
}
----

      // doctor); the resource is a thin graph mirror of the result + the dependsOn edge. The edge is

standalone path (`StandaloneResourceBuilder`) builds no `ClusterReadinessResource`, so it is
unaffected.

  public SystemdAdapterResource(
      String name,
      Map<String, Object> summary,
      Optional<ConsultationReport> consultation,
      Resource dependsOnResource) {
    super(TYPE_TOKEN, name, buildOptions(dependsOnResource));

    this.summary = Map.copyOf(summary == null ? Map.of() : summary);
    registerOutputs(asResourceOutputs(this.summary, consultation));
  }

  private static Map<String, Output<?>> asResourceOutputs(
      Map<String, Object> summary, Optional<ConsultationReport> consultation) {
    final LinkedHashMap<String, Output<?>> outputs = new LinkedHashMap<>();
    summary.forEach((key, value) -> outputs.put(key, Output.of(value)));
    consultation.ifPresent(
        report -> outputs.put("consultationReport", Output.of(report.toOutputMap())));
    return outputs;
  }
----

  public ClusterReadinessResource(
      String name,
      ClusterBootstrapReadinessVerifier.VerificationResult result,
      Optional<ConsultationReport> consultation,
      Resource dependsOnResource) {
    super(TYPE_TOKEN, name, buildOptions(dependsOnResource));

    this.verificationResult = Output.of(result);
    registerOutputs(asResourceOutputs(verificationResult, consultation));
  }

  private static Map<String, Output<?>> asResourceOutputs(
      Output<ClusterBootstrapReadinessVerifier.VerificationResult> verificationResult,
      Optional<ConsultationReport> consultation) {
    final LinkedHashMap<String, Output<?>> outputs = new LinkedHashMap<>();

    outputs.put(
        "clusterReadinessEnabled",
        verificationResult.applyValue(value -> value.readinessEnabled()));
    outputs.put(
        "clusterReadinessSkipped",
        verificationResult.applyValue(value -> !value.readinessEnabled()));
    outputs.put(
        "clusterKubeconfigPublished",
        verificationResult.applyValue(value -> value.kubeconfigPublished()));
    outputs.put("clusterApiReady", verificationResult.applyValue(value -> value.apiReady()));
    outputs.put(
        "clusterControllersEffective",
        verificationResult.applyValue(value -> value.controllersEffective()));
    outputs.put(
        "clusterRequiredControllers",
        verificationResult.applyValue(value -> value.requiredControllerRefs()));
    outputs.put("clusterReadinessSummary", verificationResult.applyValue(value -> value.summary()));
    outputs.put("handoffReady", verificationResult.applyValue(value -> value.handoffReady()));
    outputs.put("bootstrapStatus", verificationResult.applyValue(value -> value.bootstrapStatus()));

    consultation.ifPresent(
        report -> outputs.put("consultationReport", Output.of(report.toOutputMap())));

    return outputs;
  }
