== Contributing

When adding new documentation:

1. **Use AsciiDoc format** (`.adoc`) for consistency
2. **Include Mermaid diagrams** for architecture visualization
3. **Add cross-references** - link to related docs AND code in both directions
4. **Update this index** - add your document to the appropriate section
5. **Follow the pattern**: Overview → Architecture → Usage → Troubleshooting
6. **Add package-info.java** for domain-level architecture co-located with code

=== Cross-Reference Checklist

When you document a new concept:

- [ ] Add forward links FROM your doc TO related docs
- [ ] Add backward links FROM related docs TO your doc
- [ ] **Add links FROM docs TO code** (interfaces, implementations, package-info)
- [ ] **Add links FROM code (JavaDoc) TO docs** (architecture, patterns)
- [ ] Update this README with your doc in the appropriate section
- [ ] Add to the "By Concern" or "By Development Phase" navigation section if applicable
- [ ] Add package-info.java with architecture diagram if documenting a domain/package
