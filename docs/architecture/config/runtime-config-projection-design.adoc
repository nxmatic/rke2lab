= Runtime config — the `ClusterConfiguration` service was discarded (a guard note)
:toc: macro

WARNING: This is not a design. It is a *guard* against re-proposing a solution we already discarded.
If you find yourself reaching for a `ClusterConfiguration` service, stop and read this.

== The discarded solution

An early design (2026-07, discarded 2026-07-25) proposed delivering runtime config to the OSGi world
as a PULLED first-class service: a `ClusterConfiguration` `type=contract` interface, a
`RuntimeConfigRegistry` mirroring `InfraConfigRegistry`, a Config-Admin PID per runtime domain, and a
`viewFor(domain, context)` projection. Consumers would `@Reference` the service and ask for their
slice. It was never built.

== Why it was discarded

The same need — host config reaching OSGi consumers, location-transparently, partitioned by domain,
as projected views — is met by the seed-broker *amendment channel*, which is the better fit:

* *PULL became PUSH.* The host does not publish a service consumers query; it CONTRIBUTES config as
  `@Amendment` roles (FACET / WORKTREE / SOIL) at the crossing door. The domain's amend reflector
  binds them onto its wire-record; the handler receives an already-filled input.
* *Location-transparency for free.* A value crosses the frontier as a serialized JSON `String` (the
  seam rule), decoded each side — in-process today, across a process boundary tomorrow. No service
  contract needed.
* *Aligned with the gardening model.* The scenario places what the plant needs in the soil; the plant
  grows. A pulled config service is a sideways reach the model rejects.

== What shipped instead

* *The leak is dead* (commit `e9bf9656`): identity flows from the WORKTREE amendment into one
  `NodeEnvContext` projecting three view records (identity / topology / paths) — no `bioskop` literal.
* *The mechanism* is the amendment channel — see link:../osgi/seed-broker-spec.adoc[the seed-broker
  spec] (§ @Amendment: contributor / assembler, the orphan guard, the phase boundary) and
  link:../atlas/config.adoc[Atlas — config] Diagram H ("config IS the amendment").

== Do not rebuild

If you are adding a `ClusterConfiguration` service, a `RuntimeConfigRegistry`, or a
Config-Admin-per-domain config delivery: stop. That path was walked and discarded. Deliver config as
an amendment.
