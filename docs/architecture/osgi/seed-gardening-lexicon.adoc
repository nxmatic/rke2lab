= The seed-model gardening lexicon (FR-EN + the model term)
:toc: left
:toclevels: 2
:sectnums:

The seed-broker model speaks a horticultural register: a client sows a seed, the broker (the gardener)
grows it on the right plot (a domain), and the reaped result is conserved by the commissioner. This is
the reference lexicon — a general FR-EN gardening vocabulary we draw from, with a third column naming the
**seed-model term** (the code type or concept) wherever a word is actually used in the design. An empty
model column means the word is held in reserve, not yet load-bearing.

The active, load-bearing subset is summarised in
link:seed-broker-spec.adoc[the seed-broker spec]'s glossary; this file is the full reserve.

== Conservation (post-récolte) — le registre du commanditaire

Un registre ADJACENT au jardinage : ce que le commanditaire fait de la récolte, une fois la frontière
re-traversée. Le contenant SUIT la nature de ce que le jardinier rapporte (ce n'est pas un choix libre).

|===
| Français | English | Terme modèle seed

| pot | pot | **output per-resource** (niché sous sa resource) — pour une plante enracinée
| vase | vase | **export top-level** — pour des fleurs coupées (une valeur autonome)
| frigidaire | fridge | **historique de stack** (append-only) — pour des fruits conservés
| cellier | cellar | idem — conservation longue, append-only
| conserver | to keep / store | **conserver** — le commanditaire range la récolte selon sa nature
|===

== Acteurs (hors lexique de jardinage standard — nommés par le modèle)

|===
| Rôle jardinage | Dans le système | Terme modèle seed

| commanditaire / provisioner | Pulumi (via l'edge) | l'acteur réel : veut, lance (`pulumi up`), CONSERVE la récolte
| jardinier | le broker | sait faire pousser sur TOUS les terrains ; ne possède aucun ; route par coordonnée (`DefaultSeedBroker`)
| parcelle | une stack | `StackCoordinate(project, stack)` — coordonnée neutre (le docteur y projette `Patient`)
