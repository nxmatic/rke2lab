= Flox Runtime Injection Webhook
:toc: left
:toclevels: 3

Design and implementation plan for mutating admission webhook that injects flox environments into pods.

== Overview

**Goal**: Pods annotate with `flox.dev/environment`, webhook injects nix store volumes and environment variables, enabling executables from flox environments without custom container images.

**Benefits**:

- **Safer nodes**: Pods use read-only nix store, no need for privileged containers or custom images
- **Robust cluster**: Single source of truth for tool versions, consistent across all workloads
- **Easy updates**: Update flox environment → refresh DaemonSet → all pods get new tools
- **Developer experience**: Same tools locally and in-cluster

=== Request Flow

1. **User creates pod** with `flox.dev/environment: "fleet/k8s"` annotation
2. **API server** intercepts CREATE/UPDATE, sends admission review to webhook
3. **Webhook**:
   - Reads environment ConfigMap for nix store paths
   - Generates JSON patch with volume mounts + env vars
   - Returns admission response with patches
4. **API server** applies patches, creates mutated pod
5. **Pod starts** with nix store mounted, PATH includes tool binaries

== API Design

=== Annotation Format

[source,yaml]
----
apiVersion: v1
kind: Pod
metadata:
  name: kubectl-job
  annotations:
    flox.dev/environment: "fleet/k8s"  # Required: environment name
    flox.dev/verify: "true"            # Optional: add init container for verification
    flox.dev/debug: "true"             # Optional: log environment details
spec:
  containers:
  - name: main
    image: alpine:latest
    command: ["kubectl", "version", "--client"]
----

=== Injection Schema

**Volume mounts** - read-only nix store:

[source,yaml]
----
volumes:
- name: nix-store
  hostPath:
    path: /nix/store
    type: Directory

# Added to ALL containers in pod
volumeMounts:
- name: nix-store
  mountPath: /nix/store
  readOnly: true
----

**Environment variables** - PATH and metadata:

[source,yaml]
----
env:
- name: PATH
  value: "/nix/store/abc-kubectl/bin:/nix/store/def-helm/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
- name: FLOX_ENV
  value: "fleet/k8s"
- name: FLOX_ENV_VERSION
  value: "2024-01-15T10:30:00Z"
# Plus any env vars from ConfigMap environments.json
----

=== Core Components

==== Handler (pkg/webhook/handler.go)

[source,go]
----
type PodInjector struct {
    Client  client.Client
    decoder *admission.Decoder
}

func (p *PodInjector) Handle(ctx context.Context, req admission.Request) admission.Response {
    pod := &corev1.Pod{}
    if err := p.decoder.Decode(req, pod); err != nil {
        return admission.Errored(http.StatusBadRequest, err)
    }

    // Check for flox.dev/environment annotation
    envName, ok := pod.Annotations["flox.dev/environment"]
    if !ok {
        return admission.Allowed("no flox environment annotation")
    }

    // Read environment ConfigMap
    envConfig, err := p.readEnvironmentConfig(ctx, envName)
    if err != nil {
        return admission.Denied(fmt.Sprintf("environment not found: %s", envName))
    }

    // Generate patches
    patches := p.generatePatches(pod, envConfig)

    // Return patched response
    return admission.Patched("injected flox environment", patches...)
}
----

==== Injector (pkg/webhook/injector.go)

[source,go]
----
func (p *PodInjector) generatePatches(pod *corev1.Pod, env *Environment) []jsonpatch.JsonPatchOperation {
    var patches []jsonpatch.JsonPatchOperation

    // 1. Add nix-store volume
    if len(pod.Spec.Volumes) == 0 {
        patches = append(patches, jsonpatch.JsonPatchOperation{
            Operation: "add",
            Path:      "/spec/volumes",
            Value:     []corev1.Volume{nixStoreVolume()},
        })
    } else {
        patches = append(patches, jsonpatch.JsonPatchOperation{
            Operation: "add",
            Path:      "/spec/volumes/-",
            Value:     nixStoreVolume(),
        })
    }

    // 2. For each container, add volume mount + env vars
    for i := range pod.Spec.Containers {
        patches = append(patches, containerPatches(i, env)...)
    }

    // 3. If verify annotation, add init container
    if pod.Annotations["flox.dev/verify"] == "true" {
        patches = append(patches, initContainerPatch(env))
    }

    return patches
}
----

==== Environment Reader (pkg/webhook/environment.go)

[source,go]
----
type Environment struct {
    Name    string
    Paths   []string
    Env     map[string]string
    Version string
}

func (p *PodInjector) readEnvironmentConfig(ctx context.Context, envName string) (*Environment, error) {
    cm := &corev1.ConfigMap{}
    key := types.NamespacedName{
        Name:      "flox-environments",
        Namespace: "flox-system",
    }

    if err := p.Client.Get(ctx, key, cm); err != nil {
        return nil, fmt.Errorf("failed to read environments ConfigMap: %w", err)
    }

    // Parse environments.json
    var envs map[string]*Environment
    if err := json.Unmarshal([]byte(cm.Data["environments.json"]), &envs); err != nil {
        return nil, fmt.Errorf("failed to parse environments: %w", err)
    }

    env, ok := envs[envName]
    if !ok {
        return nil, fmt.Errorf("environment %s not found", envName)
    }

    return env, nil
}
----

  name: flox-webhook

    cert-manager.io/inject-ca-from: flox-system/flox-webhook-cert

- name: flox.pod.admission.nxmatic.io
  admissionReviewVersions: ["v1"]
  clientConfig:
    service:
      name: flox-webhook
      namespace: flox-system
      path: /mutate-v1-pod
  failurePolicy: Fail  # Fail closed - missing tools should block pod
  matchPolicy: Equivalent
  namespaceSelector:
    matchExpressions:
    - key: flox.dev/injection
      operator: NotIn
      values: ["disabled"]
  objectSelector:
    matchExpressions:
    - key: flox.dev/environment
      operator: Exists
  rules:
  - apiGroups: [""]
    apiVersions: ["v1"]
    operations: ["CREATE", "UPDATE"]
    resources: ["pods"]
    scope: "*"
  sideEffects: None
  timeoutSeconds: 10

== Security Considerations

=== Threat Model

**Attack surface**:

- Webhook has read access to ConfigMaps in flox-system
- Webhook can mutate all pods cluster-wide (with annotation)
- Webhook mounts host nix store into pods (read-only)

**Mitigations**:

- **Least privilege**: ServiceAccount with minimal RBAC (only read ConfigMaps in flox-system)
- **Fail closed**: `failurePolicy: Fail` - webhook down = no pods admitted
- **Read-only mounts**: nix store mounted read-only, pods cannot modify
- **Namespace isolation**: Webhook in flox-system, can be excluded via namespaceSelector
- **Audit logging**: All admission decisions logged with reason

=== Troubleshooting

**Webhook not called**:
- Check MutatingWebhookConfiguration exists
- Verify CA bundle injected by cert-manager
- Check pod has `flox.dev/environment` annotation

**Admission denied**:
- Check webhook logs for error
- Verify ConfigMap exists in flox-system
- Verify environment name in ConfigMap

**Tools not available in pod**:
- Check volume mount present: `kubectl get pod -o yaml`
- Check PATH env var: `kubectl exec pod -- env | grep PATH`
- Check nix store on node: `ls /nix/store`
