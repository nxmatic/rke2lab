= Stage A Bootstrap Contract
:toc: left
:toclevels: 3

This document defines the first executable contract for Pulumi-based management-cluster bootstrap.

== Scope

Stage A provisions and validates the management cluster seed (`bioskop`) and emits deterministic handoff outputs.

== Required inputs

[cols="1,3",options="header"]
|===
|Input |Description
|`clusterName` |Management cluster identifier (default: `bioskop`)
|`incusProfile` |Incus profile set for management seed node
|`networkProfile` |Network profile/selector used for seed node
|`sshHost` |NixOS VM endpoint used for orchestration and probes
|`readinessTimeout` |Max wait duration for API readiness
|===

== Required outputs

[cols="1,3",options="header"]
|===
|Output |Description
|`managementClusterName` |Resolved management-cluster name
|`apiEndpoint` |Control-plane endpoint for API access
|`kubeconfigRef` |Path or secret reference for bootstrap kubeconfig
|`seedNodeId` |Provider-specific identifier for the seed node
|`bootstrapPhase` |Terminal phase (`Ready` or `Failed`)
|===

== Readiness gates

. Seed node provisioned and reachable.
. RKE2 server active and healthy on seed.
. Kubernetes API reachable and responsive.
. Minimum bootstrap manifests applied successfully.

== Failure semantics

* Fail fast with explicit reason code and message.
* Emit last successful phase for resumability.
* Preserve diagnostics references for break-glass operations.

== Acceptance criteria (Slice 1)

* `pulumi up` reaches `bootstrapPhase=Ready` on a clean environment.
* Re-run is idempotent (no destructive drift for unchanged config).
* Outputs are sufficient for Stage B CAPI management-plane install.
