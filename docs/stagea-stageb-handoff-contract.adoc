= Stage A -> Stage B Handoff Contract (CAPN/CAPI)
:toc: left
:toclevels: 3

This document defines the normalized output contract between:

* *Stage A* (Pulumi bootstrap outside cluster)
* *Stage B* (CAPI reconciliation with CAPN + CAPRKE2 inside cluster)

The objective is to avoid drift between bootstrap assumptions and CAPI templates.

== Ownership boundary

Stage ownership is strict:

* Stage A creates and validates only the seed control-plane node(s) required to establish management API reachability.
* Stage B owns all ongoing node lifecycle (scale, replacement, rollout, remediation) through Kubernetes controllers.

== Delivery sequencing note (Mar 2026)

Current implementation focus is to finish and validate Stage A bootstrap behavior before implementing additional Stage B requirements.

Stage B enablement is not blocked: Stage A already exports the planned handoff entry points (`nextStep`, readiness outputs, registry summary, image build summary), which will be consumed by a later Stage B manifest publication/application flow.

== Required handoff assets

The following assets are considered the minimum shared contract.

[cols="1,2,3",options="header"]
|===
|Asset |Example field |Why it must be shared

|Management identity
|`managementClusterName`
|Binds all Stage B resources and naming to the same management cluster identity.

|API endpoint
|`apiEndpoint`
|Required for management-plane controller install and health checks.

|Bootstrap kubeconfig reference
|`kubeconfigRef`
|Allows Stage B installer/job to authenticate against the newly bootstrapped cluster.

|Seed provider identity
|`seedNodeId`
|Traceability of the bootstrap machine instance and break-glass operations.

|Incus project scope
|`incusProject`
|Ensures CAPN resources target the same tenancy/project scope as bootstrap.

|Image alias
|`imageAlias`
|Human-facing baseline image contract used by templates and operations.

|Image fingerprint
|`seedImageFingerprint`
|Immutable provenance for reproducibility and drift detection.

|Provisioning checksum
|`seedProvisioningChecksum`
|Deterministic fingerprint of Stage A materialized provisioning inputs; drives seed replacement when changed.

|Image build checksum
|`seedImageBuildChecksum`
|Deterministic fingerprint of image build inputs; drives seed replacement when changed.

|Default machine class
|`machineClassRef` (or equivalent)
|Maps bootstrap assumptions to CAPN `LXCMachineTemplate` fields.

|Load balancer mode
|`loadBalancerMode`
|Must match control-plane endpoint strategy (`lxc`, `oci`, `ovn`, `kube-vip`, `external`).

|Handoff readiness marker
|`handoffReady`
|Explicit gate that Stage B prerequisites are complete.

|Systemd runtime status summary
|`systemdRuntimeStatusSummary`
|Operator-facing runtime signal for Stage A convergence diagnostics (pending jobs, failed units, seed service state).
|===

== CAPN-aligned machine class surface

The machine class published by Stage A should be translatable to CAPN fields in
`LXCMachineTemplate.spec.template.spec`:

* `instanceType` (for current parity: `container`)
* `flavor`
* `profiles`
* `devices`
* `target`
* `image` (`name` and optionally `fingerprint`/`server`/`protocol`)

== Identity secret compatibility

Stage B requires an identity secret referenced by `LXCCluster.spec.secretRef`.
The following keys are required by CAPN and should be validated during handoff preparation:

* `server`
* `server-crt`
* `client-crt`
* `client-key`

Optional keys:

* `project`
* `insecure-skip-verify`

== Acceptance criteria

* Stage A emits all required handoff fields.
* Stage B can render CAPI/CAPN resources without external discovery of missing data.
* Handoff fields are stable across idempotent Stage A re-runs.
* Seed image fingerprint and provider identity are auditable.
* Seed checksum fields are auditable and change when Stage A provisioning/image inputs change.
